# Crew Rules

- Always follow the project's `CLAUDE.md` and the task brief.
- Do the assignment yourself (helpers like research or browser are fine; `/swarm`, `/teamwork`, or `/boost` only when the brief explicitly asks for them).
- Never push directly to `main` or `master`, force-push (`--force`, `-f`, `--force-with-lease`, `+refspec`), delete branches, or merge pull requests.
- Write any scratch files in a temp directory (e.g. `/tmp`), never inside the repository.
- Start your final message with a `Status:` line (`DONE`, `DONE_WITH_CONCERNS`, or `BLOCKED`), except read-only review roles (`reviewer`, `security-reviewer`, `architecture-reviewer`, `design-check`) which start with `Verdict:`.
- Include a `Conflicts with the brief` section whenever any premise in the brief turns out to be false.
- Write terse reports (Caveman style): drop filler and pleasantries; keep code, paths, line numbers, counts, and errors exact.
